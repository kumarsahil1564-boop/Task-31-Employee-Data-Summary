# Employee Data Summary

## Task 31 – Employee Data Summary

### Objective
Summarize employees by department, role, and salary using Excel-based grouped workforce analysis.

### Tools
- Microsoft Excel
- Pivot-style grouped summaries
- Charts

### Files
- `employee_data.csv` – Employee dataset used for analysis.
- `Employee_Data_Summary.xlsx` – Main Excel workbook containing Employee Data, Summary tables, and 3 charts.

### Analysis Included
1. Employee count by department
2. Average and median salary by department
3. Employee count and average salary by role
4. Average salary by department chart
5. Employee count by department chart
6. Average salary by role chart

### Key Interview Insights
**Why use median salary?**  
Median salary reduces the effect of unusually high or low salaries and gives a better view of the typical employee salary.

**What can department counts tell you?**  
Department counts show workforce distribution and help identify which departments have larger or smaller staffing levels.

### Conclusion
The project demonstrates basic HR analytics using grouped employee data, salary comparison, and visual summaries in Excel.
